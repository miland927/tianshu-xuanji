## 缺陷清单

### P0

**P0-1 换盘后，璇玑拿旧盘结论解读新盘**
- 复现：同一会话先起 1988-08-08 08:08（正官格、月令申），再依次起 2001-09-09 09:09、1975-05-05 05:05、2010-10-10 22:10。命盘已经变成「庚寅 丙戌 癸巳 癸亥」，璇玑仍答「正官格……月令申……大运癸亥」「第六遍……盘不动，我不改口」。
- 根因：`src/chat.js` 的 `ask()` 每次请求都带 `history.slice(-12)`，换盘时不清空；起盘发出的都是同一句「读这张盘。」，模型把新盘当成重复提问。
- 建议：生辰变了就清空 `history`；起盘那句话直接带四柱，比如「读这张盘：丙子 壬辰 乙酉 癸未」。

### P1

**P1-2 内部字段名和英文漏进回答**
- 见到的：`support 64、drain 77.44、net −13.44`、`ratio 0.4525`、`〔午冲year支子〕`、`透month、hour`、`〔zhi.冲.year〕`，手机上还出现原样的 `**定性**`。
- 建议：服务端发给模型的读数先换成中文；前端去掉或渲染 `**`；数值收进「依据」。

**P1-3 「明年」被当成今年**
- 问「明年想辞职去创业……」，答的是丙午年（2026），明年应为丁未。
- 建议：读数同时给今年、明年的干支。

**P1-4 东经没填时默认 114.93，用户看不出来**
- 灰色占位字 114.93 看起来像已填值，不填就按它算，真太阳时比北京时间早约 20 分钟，时辰边界上会错一位。
- 填 `abc` 或 `0` 也回落到 114.93（`Number(x) || 114.93`），0 是合法经度。
- 建议：预演行用朱色写「东经未填，暂按 114.93」；0 按合法值处理。

**P1-5 经度不校验范围**
- 东经填 999 照样出盘（日柱变成戊子），只提示「时区?」。
- 建议：前后端都限制 -180 到 180，越界时提示「经度越界」。

**P1-6 手机竖屏看不到点亮的金字**
- 390×844 起盘后，上方盘面里没有金字，「六十甲子」环在可视区外或被铭文栏挡住。
- 建议：手机进入「定」层时，镜头对准六十甲子环的点亮段。

**P1-7 桌面四个金字不能同时看到**
- 1440×900 下只有 2 到 3 个在视口内，其余在铭文栏渐变下或右侧屏外。
- 建议：「定」层镜头把四个点亮格框进画面。

**P1-8 隐性交互没有提示**
- 滚轮 / ↑↓ / 回车只在日期框 `title` 里；Esc 只在「收」按钮的 `title` 里；东经框没有 `title`；「乾造｜坤造」没解释。
- 预演行提示 10px、36% 透明度，几乎看不见。
- 建议：提示提亮到约 55%，末尾加「Esc 退一层」；首次聚焦时把乾造｜坤造临时显示成男｜女。

### P2

- **P2-9** 重复的柱只亮 3 格且没说明（1996-04-18 00:30，年柱、时柱都是丙子）。
- **P2-10** 起盘中途按 Esc 后改了生辰，下方仍淡显上一张盘，和输入框对不上。
- **P2-11** 顶部 `a.seg`（微 / 年 / ?）键盘聚焦时是浏览器默认橙色框，没用发丝线规则。
- **P2-12** 手机首页轮盘的字压住标题和「问璇玑」入口。
- **P2-13** 桌面落盘后对话区只剩约 263px 高，并且有可见的细滚动条。
- **子时口径**：按「23:00 换日」排（23:30 与次日 00:30 都是丙戌日戊子时），合规但界面没写明，也不能切换。建议在真太阳时那一行注「子初换日」。

规范扫描：没有发现违规圆角、投影、默认蓝色焦点框、横向溢出。`.dot` 的圆形加发光是有意设计。

## 主观体验

### 角色感和口吻
- 好：开场白「铜环转着，字是死的。你要问什么，得先说完。」立住人设；收尾短句（「动得了，稳不住」「顺中有拆，拆在根上」）有味道；问去留时先说「盘上只答得了结构，答不了该不该」，分寸对。
- 生硬：
  1. 统计数字和英文字段名夹在古雅口吻里，最伤沉浸感。
  2. 每条都是「定性 / 定位 / 走势 / 收」四段，结尾几乎都是「这一层我说到这儿」，两三条后像表单。
  3. 〔格·偏印格〕这类方括号标签太密，像调试标注；「偏印」「病药」没有白话解释。
  4. 重复时语气冲着用户（「第六遍。盘不动，我不改口」「你连问四次，我答一次」），而实际是程序拿错了盘。
- 方向：数值退到「依据」，四段式不必每次用，每次至少给一句白话结论。

### 输入时间（用户视角）
- 顺手：拨动时环实时转到日柱、预演行实时出四柱；滚轮和 ↑↓ 分段拨动，月末贴边、跨年进位都对。
- 卡人（真实按键测出）：
  1. `1996/4/18 14:06`、`199604181406`、`1996-04-18`（不带时间）都只得到「格式：YYYY-MM-DD HH:MM」，不会自动规整。
  2. 不知道几点出生的人没有入口，也不能按时辰（如「未时」）输入。
  3. 东经要自己填数字，普通人不知道出生地经度。
  4. 空框直接按 ↑，从示例日期 1996-04-18 开始拨成 1997，容易误以为是自己的输入。
  5. 滚轮玩法只在悬停提示里。

### 看结果时挡不挡视野
- 桌面：铭文栏约占左边 41%，是渐变墨色不是实底，盘面没被硬挡。问题在四个金字看不全，以及对话区太窄、读一条要滚好几下。
- 手机：栏占下方三分之二，起盘后盘里看不到金字；栏自动滚到回答，四柱被推出屏幕，回答和四柱无法同屏。
- 方向：改「定」层镜头框住四个金字；落盘后先收起「大运 / 今年」，把高度让给对话。
